# Ziyarat with Asad Ali Shah

Tourism and ziyarat website for **Syed Asad Ali Shah** — scholar-led journeys from Peterborough, UK.

- Iraq ziyarat (Najaf, Karbala, Baghdad, Madaen)
- Hajj and Umrah
- Al-Quds
- Uzbekistan (Bukhara and Tashkent)
- Bosnia

Official links: [YouTube](https://www.youtube.com/@ZiyaratwithAsad) · [Facebook](https://www.facebook.com/ZiyaratwithSyedAsad/) · [TikTok](https://www.tiktok.com/@ziyaratwithasad) · [bio.link](https://zwaas.bio.link/)

